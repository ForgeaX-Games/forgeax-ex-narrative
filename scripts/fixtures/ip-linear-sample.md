# 第七次日落

守夜人林砚第一次醒来，是在渡口的木板床上，钟楼敲了七下。他照常巡堤、点灯、记潮位。
黄昏时分堤坝崩了，浊水推着整个渔村往海里去。他抓住一根浮木，冷水灌进喉咙。

他再次醒来，仍在渡口的木板床上，钟楼敲了七下。同样的日子，同样的潮位。
这一次他跑去堤坝，发现第三段闸门的铆钉早已锈穿。他喊了一路，没人信他。黄昏时分堤坝崩了。

第三次醒来，他不再喊。他自己带了工具去补铆钉，补到一半被巡检拦下，说他私动官堤。
黄昏时分堤坝崩了。

第四次，他去找巡检的上司，编了个说得通的理由。上司答应明天派人查。可是没有明天。
黄昏时分堤坝崩了。

第五次，他去了渔村，挨家挨户劝人走。走了七户，剩下的人骂他疯子。
黄昏时分堤坝崩了，七户人活了下来，他在浪里看见他们的船。

第六次，他醒来时先去看钟楼。他发现钟楼的钟是坏的——它敲的不是七下，是六下加上堤坝
第一道裂缝开裂的那一声。裂缝在正午就有了。他终于知道要在正午之前动手。

第七次醒来，钟楼敲了七下。他没有去堤坝，也没有去渔村。他去了钟楼，把钟停了。
渔村的人听不见钟声，纷纷出门察看，于是没有人待在屋里。正午，堤坝裂开第一道缝，
人们亲眼看见了。他们自己把闸门堵上了。

黄昏时分，堤坝没有崩。林砚坐在堤上看太阳落下去，钟楼一声没响。
他不知道明天醒来是不是还在那张木板床上。
